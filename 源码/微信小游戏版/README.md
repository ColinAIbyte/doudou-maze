# 豆豆迷宫 — 微信小游戏版

**这一版是微信上架该走的路。**

## 个人主体可以发

> **更正**：本文件早先写着「个人号发不了小游戏」，**那是错的**，业主指出后查证并改正。

个人主体**可以**注册并发布微信小游戏，豆豆迷宫这种休闲/益智类正是允许的类目。限制在别处：

| 项目 | 个人主体 |
|---|---|
| 休闲 / 益智 | ✅ 可以 |
| 文化互动、角色类、牌类 | ❌ 不支持 |
| 广告变现（IAA） | ✅ 可以 |
| 虚拟支付 / 内购（IAP） | ❌ 需个体工商户或企业 |

要准备的材料：

1. **《计算机软件著作权登记证书》（软著）** —— 自己在中国版权保护中心申请，正常 1-2 个月，可付费加急到 1-5 个工作日
2. **《游戏自审自查报告》** —— 微信提供模板，自己填

**版号**：免费、无内购的休闲小游戏一般不需要。政策会变，提交前请在「微信公众平台 → 小游戏 → 类目管理」再确认一次。

## 一个不可逆的选择

小游戏本身是**小程序的一种类目**。注册账号时一旦选了「小游戏」，**一级类目就锁死了，改不回普通小程序**。

对这个项目来说没有纠结的余地——它就是个游戏，该走小游戏。同目录下还有一份 `微信小程序版/`，那是把游戏塞进普通小程序的做法，留着做技术参考，**上架不要用那一版**。

## 怎么跑起来

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开 → 新建项目 → 选择「**小游戏**」
3. 目录选到本文件夹 `微信小游戏版/`
4. AppID 那一栏点右边蓝色的 **「测试号」**（工具会用你登录的微信账号申请一个真实测试号自动填入）

   > ⚠️ 不要用「游客 AppID」（`touristappid`）—— 小游戏会报**「游客 AppID 无法使用此功能」**，游客号只对小程序开放。工程里 appid 留空就是为了让 IDE 明确提示你去点「测试号」。
5. 点「编译」

真机预览：工具栏「预览」→ 手机微信扫码。**在拿到软著、正式提交之前，扫码试玩是完全可以的**，发给朋友玩也行。

## 目录结构

```
微信小游戏版/
  game.js            入口：建 canvas → 装垫片 → 起游戏 → 合成循环
  game.json          竖屏配置
  project.config.json  开发者工具项目配置（appid 待替换）
  js/
    shim.js          DOM/BOM 垫片（document、localStorage、AudioContext…）
    ui.js            HUD 和弹层的 canvas 绘制
    core.js           【自动生成，勿手改】游戏逻辑
  工具/
    smoke.mjs        无头冒烟测试
```

## 逻辑不在这里维护

`js/core.js` 顶上写着「自动生成，请勿手改」，是认真的。它由

```bash
cd .. && node 工具/build_weapp.mjs
```

从 `pacman_fragment.html` 机械提取。

**要改游戏（关卡、难度、计分、修 bug），改网页版那一份，然后重跑上面这行命令。**

这样安排是因为两份手抄的实现一定会各自漂移：网页版调了第五关难度、修了融合幽灵的 bug，小游戏版还停在旧版本，而这种不一致通常要几周后才被发现。网页版那 1600 行里真正碰 DOM 的只有 22 个元素 id、7 处 localStorage、1 处 getComputedStyle 和两类事件——补出这一小片，比抄一遍整个游戏划算得多，也安全得多。

## 改完之后跑一遍冒烟测试

```bash
node 工具/smoke.mjs
```

它用假的 `wx` 和假的 canvas 在本机把游戏跑起来：建游戏、开局、推进 10 秒、画界面、读写排行榜、出声音。

**这一步不能省。** 语法检查通过完全不代表能跑——垫片少补一个属性，逻辑会在加载的第一行就 `ReferenceError`，而在微信开发者工具里这表现为**一片白屏**，不点开调试面板根本看不出发生了什么。写这个测试的过程中它就抓到了两个真实问题：

- 小游戏的全局对象叫 `GameGlobal`，没有 `window`，而逻辑里有四处直接写了 `window.`
- 逻辑用的是 `osc.connect(g).connect(ac.destination)` 链式写法，依赖 `connect()` 返回目标节点

## 与网页版的差异

| | 网页版 | 小游戏版 |
|---|---|---|
| 界面 | HTML + CSS | 全部画在 canvas 上（小游戏没有 DOM） |
| 操作 | 方向键 / WASD | 在迷宫上滑动 |
| 署名 | `<input>` | `wx.showKeyboard` 系统键盘 |
| 存档 | localStorage | `wx.setStorageSync` |
| 音效 | Web Audio | `wx.createWebAudioContext`（同一套合成代码） |

游戏逻辑、六张地图、难度曲线、计分规则**完全一致**——本来就是同一份代码。
