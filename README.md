# 豆豆迷宫

霓虹风格的迷宫吃豆游戏，六关递进。**打开网址就能玩，手机电脑都行。**

👉 **[点这里开始玩](https://colinaibyte.github.io/doudou-maze/)**

设计者：超级奶爸　反馈：2685897@qq.com

## 玩法

- **电脑**：方向键 / WASD 移动，`P` 暂停
- **手机**：手指在迷宫上**滑动**转向，也可以点下方的方向键

| 机制 | 说明 |
|---|---|
| 连击 | 连续吃豆叠加倍率，无上限。停一下就断 |
| 能量豆 | 吃掉后幽灵变蓝可反杀，自己还会加速 |
| 幽灵融合 | 两只受惊幽灵相撞会合成「超级幽灵」，一口吃掉分数翻倍 |
| 传送门 | 地图四角成对出现，颜色相同即相连，踩上去瞬移 |
| 神秘水果 | 赐予 10 秒穿墙能力 |
| 冲刺 | 一直走直线会越跑越快，一转弯就归零 |

奖励分：整关无伤 · 一次能量豆内全灭幽灵 · 通关剩余生命 · 全程无伤。

六关全通会放烟花，成绩可以署名存进排行榜。

> 排行榜存在你自己的浏览器里，不在服务器上，所以每个人看到的是自己的记录。

## 这个仓库

```
index.html    整个游戏，单文件，零外部依赖（不连 CDN、不加载字体图片、不请求接口）
404.html
源码/
  pacman_fragment.html   主文件，游戏逻辑都在这里
  工具/                   地图生成、校验、难度分析、自动试玩
```

`index.html` 是由 `源码/工具/build_web.mjs` 从 `pacman_fragment.html` 生成的完整网页。**要改游戏，改 `源码/pacman_fragment.html`，然后重新生成：**

```bash
cd 源码 && node 工具/build_web.mjs
```

## 开发笔记

游戏难度不是拍脑袋定的，是量出来的。`源码/工具/playtest.mjs` 是个自动试玩机器人，故意写得平庸（贪心找最近的豆 + 危险格避让，没有预判）——一个平庸机器人能通的关，人肯定能通；它永远过不去的，就是真的墙，不是手生。

```bash
cd 源码
node 工具/playtest.mjs 20   # 机器人跑六关，出通关率
node 工具/test_phase.mjs    # 穿墙 + 计分的回归测试
node 工具/validate_mazes.mjs # 地图硬底线校验，改地图后必跑
```

最近一次实测：第 1 关 100%、2 关 90%、3 关 85%、4 关 100%、5 关 75%、6 关 100%。

几条踩出来的经验：

- **幽灵速度和受惊时长都是查表，不是公式。** 试过两次复利公式，两次都出同样的问题——一个增长率不可能知道这一关「还变了什么别的」。幽灵数量、地图凶险程度各关不同，公式却按构造给每关同样的步长，第五关和第六关先后变成过墙。
- **打通死路不会降低难度，反而会提高。** 给第五关打通 4 条死路后通关率从 70% 掉到 40%——死路打通的同时也给六只幽灵开了包抄路线。
- **能量豆要避开「车流」大的格子。** 衡量标准是有多少颗其他豆子的最短路线要从它头上过。摆在中间会被路线撞开，而挑时机本来是能量豆的全部技术含量。
